## Releases

### [jaclang 0.35: placement goes markerless](https://docs.jaseci.org/community/release_notes/jaclang/)

What matters if you're upgrading:

- **The `sv`/`cl`/`na` markers are gone.** Placement is now inferred by a whole-program solver, `[placement.pins]` in `jac.toml` is the override escape hatch, and `jac fix placement` migrates an existing project in one command. `jac check --placements` explains every decision with its evidence chain.
- **Implicit returns.** The final expression of a body written without a trailing `;` is the return value: `def add(a: int, b: int) -> int { a + b }`. JSX components read especially well in the new form.
- **The full docs ship inside the binary.** `jac guide` serves the entire documentation set offline, with grep-style search, and the same corpus now drives the website and the MCP server.
- **Bare npm imports resolve.** `import from react { createContext }` works unquoted in client code, with one shared classifier driving placement, type inference, and JS emission.
- **Native got fast.** Strings carry their length for O(1) slicing, the compiler's own lexer ships as a sealed AOT library (28&times; slower than bytecode before, 3.1&times; faster now), and 0.35.1 cuts cold CLI startup roughly 3&times;.

## Releases

### [jaclang 0.37.0: one verb runs and serves, type checking on every compile](https://jaclang.org/docs/v0.37/community/release_notes/jaclang)

What matters if you're upgrading:

- **Breaking: `jac start` and `jac dev` fold into `jac run`.** Both are tombstoned. Serve with `jac run --serve`, dev with `jac run --dev`, and deploy with `jac scale deploy` now that `--scale` is gone.
- **Breaking: type checking runs on every compilation.** `jac build --no_typecheck` and the other escape hatches are gone, so a type error is a compile failure instead of the runtime crash it used to become.
- **Breaking: fixed-width numerics are real types.** `i8` through `f64` follow one value-preserving lattice on every lane, so passing an `int` into a sized parameter now needs a cast like `i32(n)`.
- **Breaking: `jac test` has its own runner.** pytest is out of the binary. Only `.jac` files are collected, with `testskip`, `testfail` and `testraises` as ambient builtins. The project suite went from 76s to 7.5s wall.
- **Breaking: a keyword is never an identifier.** Use the backtick escape (`` `skip ``), and importing typing spellings Jac already provides is a hard error.
- **New: `jac db list`, `jac db drop` and `jac db prune`.** Every database the runtime creates now records its owner, so a cluster is finally inspectable and reclaimable. `jac seal` gets its own front door too.

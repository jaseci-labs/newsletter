    <li style="margin:0 0 8px;"><strong>KEDA autoscaling.</strong> HTTP activation resources ship for scale-to-zero deployments, and <code style="font-family:'SFMono-Regular',Consolas,monospace;font-size:0.9em;background:#ece7db;padding:1px 5px;border-radius:4px;">jac start --scale</code> can pin a deployment to a specific version.</li>
    <li style="margin:0;"><strong>React Native npm dependencies</strong> are managed like any other dep, and native code can now be imported into client code as WebAssembly.</li>

  <p style="font-family:'Inter','Helvetica Neue',Arial,sans-serif;font-size:16px;line-height:1.55;color:#1f160e;margin:0 0 10px;">What matters if you&#39;re upgrading:</p>
  <ul style="font-family:'Inter','Helvetica Neue',Arial,sans-serif;font-size:15px;line-height:1.55;color:#1f160e;margin:0;padding-left:22px;"><li style="margin:0 0 8px;"><strong>Breaking: persistence is Postgres-native.</strong> The Mongo/Redis/Firestore stack is gone. Each request runs in one SERIALIZABLE transaction, zero-config runs use an embedded Postgres, and <code style="font-family:'SFMono-Regular',Consolas,monospace;font-size:0.9em;background:#ece7db;padding:1px 5px;border-radius:4px;">JAC_DB_URL</code> points at any managed one. 0.35.x session data is not migrated.</li><li style="margin:0 0 8px;"><strong>Breaking: serving is Jac-native.</strong> FastAPI, uvicorn, pydantic, and friends are gone from the runtime. Password hashing moved from bcrypt to scrypt, so pre-0.36 credentials need a reset.</li><li style="margin:0 0 8px;"><strong>Breaking: <code style="font-family:'SFMono-Regular',Consolas,monospace;font-size:0.9em;background:#ece7db;padding:1px 5px;border-radius:4px;">ReadPerm</code> and friends are now <code style="font-family:'SFMono-Regular',Consolas,monospace;font-size:0.9em;background:#ece7db;padding:1px 5px;border-radius:4px;">AccessLevel</code>.</strong> One ambient enum (<code style="font-family:'SFMono-Regular',Consolas,monospace;font-size:0.9em;background:#ece7db;padding:1px 5px;border-radius:4px;">.READ</code>, <code style="font-family:'SFMono-Regular',Consolas,monospace;font-size:0.9em;background:#ece7db;padding:1px 5px;border-radius:4px;">.CONNECT</code>, <code style="font-family:'SFMono-Regular',Consolas,monospace;font-size:0.9em;background:#ece7db;padding:1px 5px;border-radius:4px;">.WRITE</code>, <code style="font-family:'SFMono-Regular',Consolas,monospace;font-size:0.9em;background:#ece7db;padding:1px 5px;border-radius:4px;">.NO_ACCESS</code>) everywhere a level is taken.</li><li style="margin:0 0 8px;"><strong>Graph queries compile to data.</strong> Edge references lower to a query IR resolved inside the storage engine&#39;s own indexes, and every filter spelling is now equivalent.</li><li style="margin:0 0 8px;"><strong><code style="font-family:'SFMono-Regular',Consolas,monospace;font-size:0.9em;background:#ece7db;padding:1px 5px;border-radius:4px;">flow for</code> goes parallel.</strong> A lent collection fans out over threads, with unsound captures caught at compile time: about 6&times; on 8 threads.</li><li style="margin:0;"><strong>One Kubernetes pipeline.</strong> Monoliths and microservices share the same deploy target: zero-downtime rolling updates, <code style="font-family:'SFMono-Regular',Consolas,monospace;font-size:0.9em;background:#ece7db;padding:1px 5px;border-radius:4px;">--dry-run</code> previews, and a programmatic deploy SDK.</li></ul>
